確認日：2026-10-08。P0は一部確認済みです。TKCへの実接続と利用者のCSV仕様確認は未完了です。

## 観察できた環境

| 対象 | 観察結果 | 実装への反映 |
|---|---|---|
| OS / 実行環境 | Windows、PowerShell、Node.js 25.2.1、npm 11.6.2 | Windowsで起動・ビルド・テストを実施 |
| ブラウザ操作 | Computer Useのブラウザ一覧を確認。Chromeの既存タブとアプリ内ブラウザを確認 | 表示中のタブにTKC・GMO画面を見つけられなかった。無関係のタブは操作しない |
| 実TKC画面 | 観察できていない | 製品固有のURL・セレクタ・入力順序を実装しない |
| GMO / TKC実CSV | 提供なし | 列を自動確定しない。文字コード・ヘッダー行・列対応を明示して取り込む |
| P1画面 | 独立したローカル画面をPlaywrightで操作し、画像を目視確認 | 模擬データの取込み・集約・承認・中断再開を確認 |

ブラウザ一覧の確認は、TKCがこのPCで使えないことの証明ではありません。別ブラウザ・別プロファイル・別端末・未起動の可能性があります。製品名、対象ブラウザ、実CSVのローカルパスを利用者に照会済みです。

## 公式資料で確認した内容

GMOあおぞらネット銀行の公式FAQでは、法人向け入出金明細にPDFと3種類のCSV（全銀固定長・全銀CSV・当社CSV）の出力が案内されています。個人向けは当社CSVです。残高・明細画面やファイル出力の導線が記載されています。ただし、利用者が使う契約区分・CSV種類・実際の列・明細IDは確認できていません。[GMO公式FAQ](https://help.gmo-aozora.com/faqs/66865419efe214ffd63424ae/)

TKCの公開Q&Aには取引先一覧のCSV / JSON読込みと、コード・名称の一致による更新・追加・スキップの挙動が記載されています。この情報を利用者の製品にそのまま適用しません。出力列、必須項目、登録時の検証、対象製品でのコード衝突処理は実機で確認が必要です。[TKC公式Q&A](https://www.prft.tkc.co.jp/SystemqaCPNYFree/Main/QaItem.aspx?category_id=2249&item_id=0096368&system_id=292)
