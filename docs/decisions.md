# 引継ぎメモ

記録日：2026-10-08。対象：要件定義書 v0.1、P0環境確認とP1プレビュー。

- P1を先に独立実装した。実TKC・GMO画面は見つからず、実CSVも未提供のため、P0の実接続部分は未完了。
- 実TKCセレクタ・CSV列を推測で固定しない。CSVは明示的な列対応、TKCは交換可能な読取りアダプタにした。
- 法人番号と項目別出典を確認した新規先だけ集約する。カナ自動確定・曖昧な候補の自動削除・入金の売上自動分類は行わない。
- プレビュー承認・登録完了・仕訳完了を分ける。結果不明は照合待ちで、再送許可に変換しない。
- 重複原本はハッシュと行位置で再利用。IDなしの似た明細は消さない。
- ブラウザテストで、列指定JSONのプロパティ順により同一CSVの再取込みが拒否される問題を発見。キー順を正規化して比較するよう修正し、回帰検証を追加した。
- 繰り返しデモを作ると同じ会社範囲にルールが重なり競合した。デモごとに会社識別子を変え、練習を独立させた。
- バックアップ復元は稼働データを上書きしない。原本・DBのハッシュ検証後に新規保存先へ復元し、全ジョブを中断する。
- 月次の時間削減・入力誤り・残高一致は未測定。模擬23件のロジックテストと4件のブラウザテストだけで実機受入済みとはしない。
