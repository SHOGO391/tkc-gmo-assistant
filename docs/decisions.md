# 引継ぎメモ

記録日：2026-10-09。対象：要件定義書 v0.1、P0環境確認、P1プレビューと人への引継ぎ。

- P1を先に独立実装した。実TKC・GMO画面は見つからず、実CSVも未提供のため、P0の実接続部分は未完了。
- 実TKCセレクタ・CSV列を推測で固定しない。CSVは明示的な列対応、TKCは交換可能な読取りアダプタにした。
- 法人番号と項目別出典を確認した新規先だけ集約する。カナ自動確定・曖昧な候補の自動削除・入金の売上自動分類は行わない。
- プレビュー承認・登録完了・仕訳完了を分ける。結果不明は照合待ちで、再送許可に変換しない。
- 重複原本はハッシュと行位置で再利用。IDなしの似た明細は消さない。
- ブラウザテストで、列指定JSONのプロパティ順により同一CSVの再取込みが拒否される問題を発見。キー順を正規化して比較するよう修正し、回帰検証を追加した。
- 繰り返しデモを作ると同じ会社範囲にルールが重なり競合した。デモごとに会社識別子を変え、練習を独立させた。
- バックアップ復元は稼働データを上書きしない。原本・DBのハッシュ検証後に新規保存先へ復元し、全ジョブを中断する。
- 引継ぎ項目は理由・原本の行位置・確認事項・再開条件を含む。回答はSQLiteに追記し、項目内容のハッシュが変わった場合は以前の回答を履歴として扱う。
- 人の回答を記録しても、取引先登録・仕訳計上・プレビュー承認の状態は変えない。中断中でも回答を記録できるが、回答を業務データへの書込み許可や結果不明の再送許可に変換しない。
- 2026-10-09に利用者から「別のMacのブラウザで操作している」と回答があった。導入先をそのMacに決め、Mac向け起動手順とmacOS CIを追加した。現在のWindowsから別Macを操作できる接続はない。ブラウザ名・正式製品名・Mac側の操作環境は未確認。実画面を確認するまで取込・計上の操作アダプタは実装を確定しない。
- 月次の時間削減・入力誤り・残高一致は未測定。模擬29件のロジックテストと5件のブラウザテストが通った。実機受入済みとはしない。

次の操作：[Macの準備手順](mac-setup.md)から、利用者のMacのブラウザ操作環境・TKC製品・対象ブラウザ・匿名化した実GMO CSVとTKC一覧を確認し、[実機検証手順](next-live-validation.md)の読取り段階を実施する。実TKCの書込みはP2の条件がそろってから、具体的な対象の実行承認を得て進める。
